Pembahasan: Server

Apa itu Server?

Sistem komputer yang menyediakan sumber daya untuk penyimpanan data dan layanan tertentu dalam sebuah jaringan komputer. Server bertindak sebagai pusat yang melayani permintaan dari komputer client.

Fungsi Utama

  • Menyediakan layanan & resource bagi client.
  • Menyimpan dan mengamankan data terpusat.
  • Mengatur lalu lintas dan hak akses jaringan.

Jenis Server

File Server
Web Server
Database Server
App Server
